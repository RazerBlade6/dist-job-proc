# Distributed Job Worker Backend

## About

A lightweight backend for processing CSV files via distributed worker pools

## Technology Stack

- API:              Fiber
- Worker:           Go
- Database:         PostgreSQL
- Queue:            RabbitMQ
- Object storage:   MinIO locally, S3 in production
- Authentication:   JWT
- Migrations:       Goose
- Metrics:          Prometheus
- Dashboards:       Grafana
- Logs:             Loki
- Tracing:          OpenTelemetry
- Containers:       Docker
- Orchestration:    Kubernetes
- Autoscaling:      KEDA
- CI/CD:            GitHub Actions
- Infrastructure:   Terraform
- Load testing:     k6
